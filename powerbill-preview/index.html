HOW IT WORKS

Reading → bill → receipt.

01 · READ

Submit a meter reading

Customers or billing officers record the current kWh reading. Duplicate monthly readings and backwards readings are rejected server-side.

02 · BILL

Calculate from tariff

The Flask API calculates units, energy charge, fixed charge and 7.5% VAT using Decimal arithmetic and stores the tariff snapshot on the bill.

03 · PAY

Record payment safely

Payment amount comes from the locked bill row—not the browser. A unique reference produces a printable PAID receipt.

SECURITY PAGE

Threat → protection.

Security controls are explicit in the source, exercised by tests and described for project defense.

Stolen session
HttpOnly + Secure + SameSite=Lax session cookie; session renewed on login.
Cross-site request
CSRF token plus Origin enforcement on every state-changing request.
IDOR / BOLA
Server-side ownership joins; another customer's bill returns 404 and the attempt is audited.
Double payment
PostgreSQL SELECT … FOR UPDATE plus successful-payment check.
XSS
React escaping, no dangerous HTML injection, nonce-based Content Security Policy.
